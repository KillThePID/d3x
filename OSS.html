• Debian GNU/Linux is an open-source Linux distribution known for its reliability, extensive software repository, and strong community support. It has been in active development since 1993.
  • Arch Linux is an open-source, rolling-release Linux distribution that follows the KISS principle, emphasizing simplicity and minimalism. First released in 2002, it is known for its flexibility and user-centric approach.
  • GrapheneOS is an open-source, privacy and security-focused Android-based OS designed for select devices. It enhances security through advanced exploit mitigations, app isolation, and verified boot. GrapheneOS has been in active development since 2014.
  • IVPN is a privacy-focused VPN service with a strict no-logs policy, strong security, multi-hop support, and WireGuard protocol. IVPN does not require KYC and accepts cryptocurrency and cash payments. The service has been operating since 2009.
  • Proton provides encrypted email, VPN, cloud storage, and calendar services, ensuring comprehensive online privacy and protection. Proton AG, based in Geneva, Switzerland, has offered privacy-focused services since 2014.
  • Mullvad VPN is a privacy-centric VPN with a strict no-logs policy, WireGuard support, independent security audits, and multi-hop functionality. Mullvad does not require KYC and accepts cryptocurrency and cash payments. The service was launched in 2009 and is based in Sweden.
  • Standard Notes is a secure note-taking application with strong end-to-end encryption, ensuring data privacy across multiple platforms. Standard Notes has been in operation since 2017.
  • Bitwarden is an open-source password manager offering end-to-end encryption, cross-device synchronization, and self-hosting options for maximum security and control. It was first released in 2016.
  • SimpleLogin is an open-source service that provides email aliases to protect your real email address from exposure. It allows users to create, manage, and delete aliases for enhanced privacy. SimpleLogin has been operational since 2019.
  • VeraCrypt is an open-source encryption tool offering strong on-the-fly encryption (OTFE) to secure sensitive data. It is a successor to TrueCrypt and has been in active development since 2013.
  • Brave Browser is an open-source web browser designed for private browsing, with built-in tracker blocking, an ad blocker, and optional cryptocurrency-based rewards. Brave was first released in 2016.
  • Signal is an encrypted messaging platform offering secure instant messaging, voice calls, and video calls with end-to-end encryption. Signal has been in operation since 2014 and is developed by the non-profit Signal Foundation.
  • YubiKey is a hardware security key providing secure two-factor authentication, ensuring safe logins for online accounts. Developed by Yubico, YubiKey has been available since 2008 and supports multiple authentication protocols.
  • Bisq Network is a decentralized platform for buying and selling cryptocurrency privately through peer-to-peer transactions. Bisq is open-source, requires no KYC, and has been operational since 2014.
  • Cake Wallet is an open-source, non-custodial cryptocurrency wallet supporting Bitcoin, Ethereum, Monero, and Litecoin. It gives users full control over their private keys and has been available since 2018.
  • Railway Wallet is an open-source cryptocurrency wallet built on the RAILGUN privacy network. It utilizes zero-knowledge cryptography for private transactions across Ethereum, BNB Chain, and Polygon. Railway Wallet has been in active development since 2023.
