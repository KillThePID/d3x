• Debian GNU/Linux - Debian is an open-source Linux distribution known for its reliability, extensive software repository, and strong community support. I currently run Debian Testing with KDE.
  • Arch Linux - Arch is an open-source, rolling-release Linux distribution that follows the KISS principle, emphasizing simplicity and minimalism in its design and approach.
  • GrapheneOS - GrapheneOS is an open-source, privacy and security-focused Android operating system that runs on selected devices.
  • IVPN - IVPN is a privacy-focused VPN with no logs, no KYC, and strong security, supporting WireGuard and offering multi-hop connections.
  • Proton - Proton provides encrypted email, VPN, and other secure services, ensuring privacy for users seeking complete online protection.
  • Mullvad VPN - Mullvad is a privacy-focused VPN with no logs, no KYC, independent audits, and support for Bitcoin and Monero payments.
  • Standard Notes - Standard Notes is a free, secure note-taking app featuring strong end-to-end encryption across multiple platforms, ensuring data privacy.
  • Bitwarden - Bitwarden is an open-source password manager that provides end-to-end encryption to store and sync credentials across all devices securely.
    • SimpleLogin - SimpleLogin is an open-source service that provides email aliases, protecting your real email address from unwanted exposure.
  • VeraCrypt - VeraCrypt is an open-source encryption tool offering strong on-the-fly encryption (OTFE) for securing sensitive data on your device.
  • Brave Browser - Brave is an open-source browser that offers private browsing; it shields against tracking and blocks ads.
  • Signal - Signal is an encrypted messaging platform that offers secure instant messaging, voice calls, and video calls for privacy-conscious users.
  • YubiKey - YubiKey is a hardware security key that provides secure two-factor authentication, ensuring safe logins for online accounts.
  • Bisq Network - Bisq Network is a decentralized platform for buying and selling cryptocurrency privately, with peer-to-peer transactions and open-source software.
  • Cake Wallet - Cake Wallet is an open-source, non-custodial cryptocurrency wallet supporting Bitcoin, Ethereum, Monero, and Litecoin.
  • Railway Wallet - Railway is an open-source wallet built on the RAILGUN privacy network, enabling secure transactions across Ethereum, BNB Chain, and Polygon.
